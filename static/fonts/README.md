# Fonts

Self-hosted fonts referenced by `static/css/lucid.css`. No external font CDN is used.

Expected files:

| File | Font | License |
|---|---|---|
| `Montserrat-Variable.woff2` | Montserrat (variable, weights 300-800) | SIL Open Font License 1.1 |
| `Cinzel-Variable.woff2` | Cinzel (variable, weights 400-900) | SIL Open Font License 1.1 |

Until these files are added, pages fall back to system fonts (sans-serif for body, serif for display).
Keep each font's `OFL.txt` license file next to it.
